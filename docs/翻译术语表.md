# 翻译术语表

本表为 X 推荐算法开源仓库中文翻译过程中固定的中英术语对照，供各模块译文保持一致。术语原则上保留英文原词，首次出现时以中文注释说明；下方列出约定译法。

| 英文术语 | 中文译法 / 注释 | 说明 |
| --- | --- | --- |
| For You feed | For You 信息流（为你推荐信息流） | X 首页主打的个性化推荐时间线 |
| heavy ranker | heavy ranker（重型排序器 / 主排序模型） | 对候选做最终重排的模型 |
| candidate sourcing | candidate sourcing（候选来源 / 候选召回） | 召回候选帖子的环节 |
| out-of-network (OON) | 网外（网络外内容） | 来自浏览者未关注账号的内容 |
| in-network | 网内（网络内内容） | 来自浏览者已关注账号的内容 |
| simclusters | SimClusters（聚类召回） | 按互动关系聚类的召回来源 |
| Phoenix | Phoenix（召回与排序模型） | 基于向量检索的召回及 Transformer 排序模型 |
| Thunder | Thunder（网内内存缓存） | 在内存中保存关注账号近期帖子的服务 |
| candidate-pipeline | 候选流水线 | 组装推荐流水线的通用框架 |
| home-mixer | Home Mixer（首页混排服务） | 构建 For You 信息流的核心服务 |
| scoring | 打分 / 评分 | 为帖子计算分值 |
| ranking | 排序 / 排名 | 决定帖子的展示顺序 |
| retrieval | 召回 / 检索 | 从候选库中找出相关帖子 |
| recall | 召回（查全） | 指系统能覆盖到的候选范围 |
| hydrator | 数据补全（水合器） | 为候选补全文本、作者、媒体等字段 |
| source | 来源 | 流水线中产出候选的环节 |
| filter | 过滤器 | 流水线中筛除帖子的环节 |
| scorer | 打分器 | 流水线中计算分值的环节 |
| selector | 选择器 | 流水线中做筛选 / 混排的环节 |
| side effect | 副作用 | 响应发出后的异步处理（记录、缓存刷新等） |
| visibility filtering | 可见性过滤 | 决定帖子能否对浏览者展示 |
| interstitial | 插页提示 | 需浏览者点击穿过的提示页（如成人内容） |
| label | 标签 | 其他系统施加到帖子 / 账号上的标注 |
| botmaker | Botmaker（规则引擎） | 标注规则的语言、编译器与运行时 |
| scarecrow | Scarecrow（事件标注服务） | 对事件实时施加标签规则的服务 |
| Grox | Grox（内容理解分类器） | 帖子发布时运行的文本 / 媒体分类器 |
| embedding | 嵌入（向量表示） | 将文本 / 图像等映射为向量 |
| PageRank | PageRank | 在关注图与互动边上计算账号质量 |
| Transformer | Transformer（变换器模型） | 用于排序预测的神经网络结构 |
| determinantal point process (DPP) | 行列式点过程（DPP） | 用于降低相邻帖子相似度的重排方法 |
| blending | 混排 | 将帖子与广告、推荐关注等交错 |
| engagement | 互动 / 参与度 | 点赞、转发、回复等用户行为 |
| dwell time | 停留时长 | 浏览者在帖子上停留的时间 |
| recommendation | 推荐 | 系统主动向浏览者展示的内容 |
| candidate | 候选（候选项） | 进入流水线的待排序帖子 |
